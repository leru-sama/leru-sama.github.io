代码链接Shortcode使用指南

概述

codelink shortcode 是一个自定义的Hugo shortcode，用于在Markdown文档中创建指向代码文件的链接。这些链接具有统一的样式，并且支持链接到特定的代码行。

语法


  
  显示文本

参数说明

参数类型必需说明
path字符串✅相对于 static/code/ 的路径，支持深层目录结构
text字符串❌链接显示的文本，默认为路径
line数字❌行号，会在URL中添加锚点

使用示例

1. 基本用法

查看 
  
  example_project/main.cpp
 的实现。

效果：查看 example_project/main.cpp 的实现。

2. 自定义显示文本

配置文件位于 
  
  项目配置
。

效果：配置文件位于 项目配置 。

3. 链接到特定行

在 {{< codelink path="example_project/main.cpp" line="25" text="第25行" >}} 定义了计算平均值的方法。

效果：在 第25行 定义了计算平均值的方法。

4. 深层目录结构示例

深度学习模型实现见 
  
  CNN模型
。

效果：深度学习模型实现见 CNN模型 。

5. 数据分析项目示例

我们使用 
  
  数据分析器
 来处理数据。

效果：我们使用 数据分析器 来处理数据。

代码链接功能演示

这个页面演示了如何使用 codelink shortcode 来链接到存储在 static/code/ 目录中的代码文件。

功能说明

通过 codelink shortcode，你可以：

  1. 链接到项目中的特定代码文件
  2. 指定显示的文本
  3. 可选地链接到特定行号

使用方法

基本用法

{{< codelink path="example_project/main.cpp" >}}

效果： example_project/main.cpp

自定义显示文本

{{< codelink path="example_project/main.cpp" text="主程序文件" >}}

效果： 主程序文件

链接到配置文件

{{< codelink path="example_project/config.toml" text="项目配置" >}}

效果： 项目配置

链接到特定行号

{{< codelink path="example_project/main.cpp" line="25" text="calculateAverage方法" >}}

效果： calculateAverage方法

深层目录结构示例

{{< codelink path="ml/models/neural_networks/cnn.py" text="CNN模型实现" >}}

效果： CNN模型实现

目录结构

代码文件存储在 static/code/ 目录中，支持任意深度的目录结构：

static/
└── code/
    ├── example_project/
    │   ├── main.cpp
    │   └── config.toml
    ├── data_analysis/
    │   ├── analyzer.py
    │   └── README.md
    ├── ml/
    │   └── models/
    │       └── neural_networks/
    │           ├── cnn.py
    │           └── rnn.py
    └── scripts/
        ├── build.sh
        └── deploy.sh

参数说明

  • path (必需): 相对于 static/code/ 的路径，支持深层目录结构
  • text (可选): 链接显示的文本，默认为路径
  • line (可选): 行号，会在URL中添加锚点
