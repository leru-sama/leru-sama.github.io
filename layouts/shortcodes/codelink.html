{{- $path := .Get "path" -}} {{- $text := .Get "text" | default $path -}} {{- $line := .Get "line" -}} {{- if not $path -}} {{- errorf "codelink shortcode: missing 'path' parameter" -}} {{- end -}} {{- $code_url := printf "code/%s" $path -}} {{- if $line -}} {{- $code_url = printf "%s#L%d" $code_url (int $line) -}} {{- end -}} {{ $text }}
